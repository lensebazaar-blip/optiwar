# OptiWar Favicon Package

## Complete Cross-Device Favicon Set

This package contains favicons optimized for every device and screen size, from the smallest browser tab to the largest smart TV.

### What's Included

| Category | Files | Sizes |
|----------|-------|-------|
| **Browser Favicons** | `favicon.ico`, `favicon.svg`, `favicon-{16,32,48,64,96,128,256}.png` | 16px → 256px |
| **Apple Touch Icons** | `apple-touch-icon-{57,60,72,76,114,120,144,152,167,180}.png` | 57px → 180px |
| **Android / Chrome** | `android-chrome-{36,48,72,96,144,192,256,384,512}.png` | 36px → 512px |
| **Windows Tiles** | `mstile-{70,144,150,310x150,310x310}.png` | 70px → 310px |
| **Safari Pinned Tab** | `safari-pinned-tab.svg` | Vector |
| **Scalable Vector** | `favicon.svg` | Vector |
| **Smart TV** | `tv-icon-{512,1024}.png`, `tv-banner-{1280x720,1920x1080,3840x2160}.png` | 512px → 4K |
| **Config Files** | `site.webmanifest`, `browserconfig.xml` | — |

### Device Coverage

- **Desktop Browsers**: Chrome, Firefox, Safari, Edge, Opera, Brave (all sizes covered)
- **Mobile Browsers**: iOS Safari, Android Chrome, Samsung Internet, Firefox Mobile
- **iOS Devices**: iPhone (all generations), iPad, iPad Mini, iPad Pro
- **Android Devices**: All densities (ldpi → xxxhdpi)
- **Windows**: Start menu tiles, taskbar pins, Edge favorites
- **macOS**: Safari pinned tabs, bookmarks, dock
- **Smart TVs**: Google TV, Android TV, Samsung Tizen, LG webOS, Apple TV, Fire TV
- **Game Consoles**: PlayStation, Xbox (browser-based)
- **PWA / Web Apps**: Splash screens, home screen icons

### Installation

1. Copy all files to your website's root directory (or adjust paths as needed)
2. Add the contents of `html-head-snippet.html` to your `<head>` tag
3. Verify `site.webmanifest` and `browserconfig.xml` paths match your deployment

### Design

The favicon uses an **OW monogram** (OptiWar initials) with the brand's signature black/white split design:
- Left half: Black background with white **O**
- Right half: White background with black **W**

This ensures readability at all sizes while maintaining the brand identity.
